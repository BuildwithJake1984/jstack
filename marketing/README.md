# Marketing

Lessons, skills, tools, and templates for **go-to-market work**: campaigns, creative production, email, and growth—not the application runtime stack.

## Category rule

Place material here by **use**, not underlying tech. AI tools used for marketing (video, voice, ads) belong in `marketing/tools/` even when they are also “AI products.” Runtime and shipping tools stay in [`development/tools/`](../development/tools/README.md); coding agents stay in [`ai-agents/tools/`](../ai-agents/tools/README.md). See [CONVENTIONS.md](../CONVENTIONS.md#category-by-use-not-tech).
