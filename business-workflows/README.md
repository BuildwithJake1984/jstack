## Scope and permissions

The existing design/product-oriented skill is placed here because its stated outcome is interface quality. It can also help a personal project; placement is navigation, not a restriction. Empty legacy skill indexes and the unassigned project-playbook guide are retained for review, not presented as finished workflows. See the [migration notes](../insights/repository-reorganization.md#placement-decisions).

Start with [Getting Started](../GETTING_STARTED.md). Read and discuss a workflow before choosing whether to take any action. J-Stack does not run the linked skills or grant permissions.
