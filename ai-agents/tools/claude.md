# Claude — Anthropic models, apps, and APIs

## When to use

- Choosing or integrating Anthropic models (Claude) for agents, chat, or batch workflows.
- Comparing Claude capabilities, context windows, and tool/MCP support against other frontier labs.
- Tracking Claude Code, SDK, and platform release notes for JStack agent setups.

## What it is

[Anthropic](https://www.anthropic.com/) builds the **Claude** model family and ships it through consumer apps, an API, and developer products such as **Claude Code**. Official docs live at [docs.anthropic.com](https://docs.anthropic.com/) (including API reference, prompts, and release notes).

## Where it fits in Jake's stack and JStack

Claude is a **default frontier lab** in Jake's AI layer: coding agents (Cursor, Claude Code), long-context reasoning, and product features that need reliable instruction-following. In JStack it sits under [`ai-agents/tools/`](README.md) alongside other labs, with lessons in [`ai-agents/lessons/`](../lessons/README.md) and design/agent tooling (for example [Paper](../../design/tools/paper.md) MCP) documented in [`design/tools/`](../../design/tools/README.md).
