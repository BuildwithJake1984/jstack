# Cursor — AI editor and cloud agents

## When to use

- Setting up or documenting **agentic coding** workflows (rules, skills, MCP, Cloud Agents).
- Choosing when Cursor fits versus terminal-only agents or other IDEs.
- Tracking Cursor product and docs changes that affect Jake's daily ship loop.

## What it is

[Cursor](https://cursor.com/) is an **AI-native code editor** built on VS Code: inline and chat agents, codebase context, extensions, and team/cloud features. Product and setup docs live at [docs.cursor.com](https://docs.cursor.com/).

## Where it fits in Jake's stack and JStack

Cursor is the **default place Jake writes and runs agents** against [GitHub](../../development/tools/github.md) repos deployed via [Vercel](../../development/tools/vercel.md) and [Supabase](../../development/tools/supabase.md). JStack catalogs it in [`ai-agents/tools/`](README.md) next to frontier labs ([Claude](claude.md), [OpenAI](openai.md), etc.) because it orchestrates models and tools—not because it replaces them.
