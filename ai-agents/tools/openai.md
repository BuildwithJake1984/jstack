# OpenAI — models, API, and Codex

## When to use

- Integrating OpenAI models via the Platform API or evaluating new model tiers.
- Following Codex, SDK, and platform changelog items that affect agent workflows.
- Comparing OpenAI tooling with other frontier labs in the stack.

## What it is

[OpenAI](https://openai.com/) provides frontier **GPT** and related models through the **OpenAI Platform** ([platform.openai.com/docs](https://platform.openai.com/docs)), consumer products, and coding-oriented offerings such as **Codex**. Product and research news are published on the OpenAI site; platform changes are tracked in the [platform changelog](https://platform.openai.com/docs/changelog).

## Where it fits in Jake's stack and JStack

OpenAI is a **core frontier option** for APIs, embeddings, and agent backends when Claude or xAI are not the better fit. JStack catalogs it in [`ai-agents/tools/`](README.md) and ties agent architecture guidance to [`ai-agents/lessons/`](../lessons/README.md) (for example graph-style AI features).
