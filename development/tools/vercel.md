# Vercel — frontend cloud and deployments

## When to use

- Deploying **Next.js** or other frontend frameworks with preview URLs per branch.
- Using Vercel's platform features (analytics, firewall, storage integrations, AI SDK patterns).
- Tracking Vercel changelog items that affect Jake's production apps.

## What it is

[Vercel](https://vercel.com/) is a **frontend cloud**: git-connected deployments, global CDN/edge, serverless and edge functions, and first-class **Next.js** support. Platform docs: [vercel.com/docs](https://vercel.com/docs).

## Where it fits in Jake's stack and JStack

Vercel is the **primary production host** for Jake's Next.js apps. JStack documents it in [`development/tools/`](README.md) with [Next.js](nextjs.md) and [GitHub](github.md); backends often pair with [Supabase](supabase.md). Agent and design workflows remain in [`ai-agents/`](../../ai-agents/tools/README.md) and [`design/tools/`](../../design/tools/README.md).
