# ShadcnCraft

[ShadcnCraft](https://shadcncraft.com/) extends the official shadcn/ui primitives with production-ready React components, full interface blocks, pages, applications, and a matching Figma system. Its distinguishing value is the 1:1 connection between design assets and implementation code, including agent skills and MCP-oriented workflows for Codex, Claude Code, and Cursor.

## Current library

- **282 blocks** across marketing, application, ecommerce, AI, and official shadcn categories.
- **124 components** with deeper states and product-oriented variants.
- Matching Figma and React structures.
- Light and dark themes plus all eight shadcn styles.
- Figma plugin for creating styles, importing themes, syncing tokens, and exporting React.
- Agent skills for token synchronization and Figma-to-code workflows.
- Pages and complete Next.js applications.
- UI Rules companion product for centralizing design and brand guidance for AI tools.

Counts and offerings can change, so verify the live catalog before choosing a tier.

## Free versus paid

The live catalog identifies a small free collection—currently eight free blocks and fifteen free components—alongside official shadcn items. Most of the distinctive application, marketing, ecommerce, and AI inventory belongs to the paid Pro products.

## Best use

ShadcnCraft is most useful when the project wants to keep shadcn/ui as the technical foundation but avoid assembling every complex screen from primitives:

- Application shells, navigation, sidebars, and dashboards.
- Tables, calendars, activity feeds, uploads, and messaging surfaces.
- Marketing heroes, pricing, testimonials, social proof, and CTAs.
- Ecommerce product, cart, checkout, and category layouts.
- Figma-first client design that needs a close React handoff.
- Agent builds where shared tokens and exact component definitions reduce drift.

## Relationship to shadcn/ui

- **shadcn/ui remains the project's primary foundation.**
- ShadcnCraft is a paid acceleration and design-layer option built on that foundation.
- Use free or purchased ShadcnCraft blocks when they materially reduce design and assembly work.
- Continue adapting everything to the target product’s own tokens, content, workflows, accessibility needs, and component inventory.

## Adoption guidance

- Start with the free tier and test one representative application block and one marketing block.
- Verify code quality, accessibility, mobile behavior, state coverage, and compatibility with the project’s current shadcn version.
- Do not install agent skills or MCP integrations solely because the library offers them; review and approve them separately.
- Keep purchased source private and follow the license’s redistribution restrictions.
- Record the licensed seat owner and tier so future agents know which assets are authorized.

## Classification

**Freemium shadcn extension with one-time paid Figma and React tiers, lifetime updates, and commercial-use licensing.**
