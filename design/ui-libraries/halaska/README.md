# UI by Halaska - AI product UI kit

A React UI kit for AI products with roughly 100 styled components and 38 UX patterns covering chat, streaming, approvals, agent activity, recovery, generative UI, and canvas workflows. It is distributed as a single editable React file plus an installation prompt for coding agents.

## Access and licensing

**Free.** The official FAQ states that the kit is MIT licensed and may be used commercially.

## Use notes

Use for AI-product screens and workflow patterns while keeping shadcn/ui as the project's default general-purpose foundation. Inspect the downloaded source, preserve existing application behavior, and verify accessibility, responsive behavior, dependencies, and reduced-motion states before adoption. This is a reference, not a registered agent skill.
