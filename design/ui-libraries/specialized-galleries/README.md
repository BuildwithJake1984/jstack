# Specialized design inspiration galleries

A group of focused visual-reference sites for finding full websites or one specific page section. These are **inspiration sources**, not component packages. Recreate ideas in the target product’s own system instead of copying another designer’s imagery, brand assets, or complete composition.

## When to use each

- Start with **A1** when the product category, visual style, technology, or color direction matters.
- Use **Bento Grids** when arranging several capabilities, statistics, screenshots, or content types into one modular section.
- Use **Supahero** for first-viewport storytelling, headline hierarchy, primary CTAs, and product imagery.
- Use **Navbar Gallery** when deciding information architecture and desktop/mobile navigation behavior.
- Use **Unsection** when a single page section is weak but the rest of the page direction is already established.
- Use **Footer Design** to make the bottom of a marketing site feel intentional rather than leftover.
- Use **404s Design** for branded failure states that help users recover.
- Use **SaaSpo** for software-marketing conventions and conversion-oriented SaaS page patterns.
- Use **Posts Design** for a brand's X, LinkedIn, launch, and educational-content visual system.

## A1 in a design workflow

A1 is the strongest general-purpose candidate in this group because it combines broad inspiration with filters, saved boards, full-page captures, and an MCP. Its gallery remains free, so start there. Consider Pro only if the project regularly needs shared boards, full-page screenshots, or enough MCP traffic to exceed the free limit.

## Usage boundaries

- Screenshots depict work owned by their original creators.
- Use examples to identify patterns: hierarchy, spacing, section order, contrast, motion, and interaction.
- Do not treat gallery inclusion as a license to reuse images, logos, illustrations, copy, or source code.
- Combine ideas from multiple references and produce an original, accessible, responsive implementation.
- Verify live-site behavior because gallery screenshots may not show hover, keyboard, mobile, reduced-motion, loading, or error states.
