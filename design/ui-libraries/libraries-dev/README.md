# Libraries.dev - UI effects for AI agents

Five React effect libraries for border beams, thinking orbs, gooey interfaces, liquid metal, and image-generation loaders. Each library can be installed separately and configured with coding agents.

## Access and licensing

**Free core plus optional paid Pro.**

- All five npm libraries are free, MIT licensed, and allowed in unlimited personal and commercial projects.
- Pro is $9/month for one seat. It adds the Studio, deeper customization, Pro presets and recipes, priority support, and updates while the plan is active.
- A $149 one-time Solo lifetime option is also advertised.

You do **not** need to keep the monthly subscription for components or configurations already downloaded or exported. Cancellation ends future Studio access, downloads, and updates, but existing project files keep working and remain licensed. Pro content may be used in products but may not be redistributed as a competing component or template library.

## Thinking Orbs

The [Orbs playground](https://libraries.dev/orbs) exposes interactive animated orb presets for thinking, voice, processing, and ambient AI states. It is part of the existing Libraries.dev family, not a separate library entry.

Use it for focused assistant states or a restrained the project “energy core.” Always provide a non-animated or reduced-motion state, confirm contrast around overlaid content, and profile WebGL or canvas cost on mobile devices.

## Use notes

Start with the free packages. Consider Pro only when Studio customization or Pro presets materially save time. Review WebGL and peer dependencies, bundle cost, accessibility, and reduced-motion behavior before shipping. This is a reference, not a registered agent skill.
