# Typeface.fyi — visual typeface discovery

A typography-discovery reference for browsing expressive typefaces and finding candidates for identity, editorial, product, and web work.

## Access and licensing

**Free to browse.** Typeface.fyi is a discovery surface, not a universal font license. Pricing and permitted use belong to the linked type foundry or distributor and must be checked for each font.

## Best use

Use during early creative direction to expand beyond default web fonts, compare personality, and create a shortlist before checking availability and licensing.

## Cautions

- Verify separate desktop, webfont, app, social, logo, and client-transfer rights where applicable.
- Confirm character coverage, weights, variable axes, file formats, and performance.
- Prefer a fallback or readily licensed alternative before locking a client system.
- Do not download or redistribute font files unless the specific license permits it.
