# FeralUI

[FeralUI](https://feralui.dev/) is a small showcase of playful, physics-driven React and TypeScript elements. The work emphasizes tactile motion, real-time physics, unusual interactions, and deliberately whimsical interface moments.

## Notable experiments

- **PullCord** — a Verlet-physics ceiling cord used as a theme switch.
- **ClawCaptcha / playcaptcha** — a keyboard-accessible claw-machine interaction that can sit in front of real verification.
- **Gradient Builder** — soft gradients drawn from traditional Japanese colors.
- **Screenery** — finished application screens with signature interactions.
- **DeskFolio** — a small spring-driven portfolio book with page turns.
- **Blob** — a squishy mascot inside a logout modal.
- **AniMaps** — animated route maps that can be exported and shared.
- **Fur** — interactive canvas-rendered fur.
- **Vacuum** and **Crumple** — playful destructive-action metaphors.
- **Hologram** — a light-reactive foil-card effect.

## Best use

FeralUI is most valuable as a **creative interaction laboratory**, not as a general component foundation. Use it when a screen would benefit from one memorable physical behavior:

- Brand mascot reactions or playful planet interactions.
- Theme switching through a physical metaphor.
- Delightful confirmations, deletion states, or empty states.
- Portfolio and case-study storytelling.
- Experimental micro-tools where the interaction is part of the product.

## Adoption guidance

- Open the exact component repository and verify its license before copying code or assets.
- Test touch, keyboard, reduced-motion, CPU usage, and low-powered devices.
- Keep critical actions understandable without the novelty interaction.
- Treat CAPTCHA-like experiments as presentation layers, never replacements for real security controls.
- Prefer one signature interaction per screen so playfulness does not overwhelm usability.
