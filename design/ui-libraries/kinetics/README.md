# Kinetics — spring-physics motion for web interfaces

Gallery of ~153 spring-physics interface animations (stiffness/damping tuned). Each entry has a live demo plus copy-paste **CSS**, **React**, and an **AI prompt**.

## Use for

App and site frontends when you want motion with weight — buttons, cards, loaders, toasts, steppers, and similar. Steal spring params and patterns; match the project's existing stack (don't force a second animation system).
