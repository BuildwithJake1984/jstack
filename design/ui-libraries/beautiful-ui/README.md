# Beautiful UI - AI-native interface primitives

## When to use

- Sourcing MIT AI-interface primitives alongside AICSS or UI by Halaska.
- Adapting copied patterns to the destination design system before commit.

Listed in [UI Components catalog](../components/).

A collection of polished primitives for AI-native interfaces, including loading and thinking states, streaming text, approvals, tool chips, task rows, prompt bars, context cards, diffs, tables, flowcharts, code blocks, and agent screens.

## Access and licensing

**Free.** The components are published under the MIT License for personal and commercial use. The email form is an optional newsletter for new components and updates; it is not a paid subscription or a condition of the software license.

Keep the MIT copyright and permission notice with substantial copies of the source.

## Use notes

Use as an AI-interface pattern and source reference alongside AICSS and UI by Halaska. Inspect copied code and dependencies, adapt styling to the destination design system, and verify accessibility and interaction states. This is a reference, not a registered agent skill.
