# Kobra - React component system

A polished React component system built around shadcn-compatible installation, Tailwind, Base UI, motion, interface sound, a Figma kit, agent guidance, and an MCP server. The Input OTP component is included in Kobra's free set.

## Access and licensing

**Free personal tier plus paid commercial license.**

- Free: 10 components, including Input OTP, with source access and no account required. Kobra labels this tier **personal use only**.
- Individual: $199 one time for one designer or developer, all components, unlimited commercial projects, lifetime updates, MCP access, and support.
- Team: one-time seat-based pricing; verify the current total for the required seat count.

Do not treat a component being publicly copyable as permission for commercial use. Client work and other business products require the appropriate commercial license unless Kobra changes its terms.

## Use notes

Kobra is strong value when a commercial project needs its broader design system, motion, Figma alignment, or agent integration. Review dependencies, accessibility, motion, sound defaults, and license scope before adoption. This is a reference, not a registered agent skill.
