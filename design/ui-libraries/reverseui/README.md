# ReverseUI

[ReverseUI](https://reverseui.com/) is an animated React/Framer Motion component collection covering navigation, footers, logos, text and visual effects. A useful supplemental reference for the **animated marketing websites**, especially [Proximity Navigation](https://reverseui.com/components/proximity-navigation), [Aurora Footer](https://reverseui.com/components/aurora-footer) and [Particle Text Reveal](https://reverseui.com/components/particle-text-reveal). These are candidates, not approved designs or installed dependencies.

**Access and license:** The [official pricing page](https://reverseui.com/pricing) advertises a free source subset without an account and premium lifetime developer/team licenses, commercial use including client projects, and private GitHub access after purchase. Full license/redistribution terms and checkout pricing are unverified; no the project purchase or premium access was verified. Confirm terms before adopting source.

Check the chosen component's styling variant, mobile behavior, accessibility, reduced motion and performance during later design review. Keep shadcn/ui as the primary foundation. This entry copies no component code and authorizes no purchase or website build.
