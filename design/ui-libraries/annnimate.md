# Annnimate — GSAP motion components

## When to use

- Motion inspiration or implementable GSAP patterns for scroll, hover, text, and page transitions.
- Prefer when a project is already GSAP-oriented or needs highly directed timeline animation.
- Use Amicro or Kinetics for lighter micro-interactions and spring-based recipes.

Listed in the [UI Components catalog](components.md).

Production-oriented **GSAP** animation components for **React**, **Vue**, and HTML: scroll reveals, magnetic buttons, text effects, page transitions, galleries, and shaders. Browse and preview freely; paste-ready code is generally part of the paid library.

## Notes

- **Reference only** — do not register it as an agent skill or auto-install anything.
- **Commercial library** — verify the current subscription and license before shipping downloaded code in a client project.
- GSAP itself is free to use under its current standard license, but Annnimate access and component rights are separate.
- Claims such as SSR compatibility, type safety, and reduced-motion support still require verification in the target application.
- Landmark Kits are separate add-on products rather than access to the complete library.
