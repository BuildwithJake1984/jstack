# Amicro — React micro-interactions & UI components

MIT open-source gallery by **Syed Subhan** ([@SubhanHQ](https://x.com/SubhanHQ) / [Subhan-code](https://github.com/Subhan-code)). Free, copy-paste React micro-interactions and UI components powered by Motion — buttons, cards, carousels, loaders, and related micro-transitions.

## Use for

App and site polish when looking for interaction patterns. **Not** a drop-in dependency — steal interaction ideas and match the project's existing styling system.

Upstream also offers copy-to-code, CLI (`npx @subhanhq/amicro@latest …`), and a shadcn registry path. Treat Amicro as **pattern inspiration**; review any pasted or CLI-added TSX before commit (same as any UI kit). **Do not auto-run the CLI from agents without the user asking.**

**Stack assumptions upstream:** React 18/19, Tailwind, Motion/framer-motion — match the project's existing stack when adapting.
