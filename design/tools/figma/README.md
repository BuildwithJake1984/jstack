# Figma — collaborative design and design systems

[Figma](https://www.figma.com/) is a collaborative canvas for interface design, prototyping, and design–development handoff. For systems work, Figma emphasizes **reusable components**, **variables** (for values such as color and typography that switch across contexts like light and dark mode), and **team libraries** so multiple files stay aligned to one foundation.

Figma’s design-systems material describes **variables** that propagate updates across designs, **slots** for flexible component instances, and workflows where design context feeds team tools—including agent features marketed on Figma’s site. **Dev Mode** gives developers a shared space to inspect specs (dimensions, colors, spacing) from the same files designers use.

Figma also documents connections between design and code (for example component sync and MCP-oriented guides on their site). Treat those integrations as product capabilities to validate against your team’s plan and security requirements.

## Capabilities

- **UI design and prototyping** for apps, websites, and design systems.
- **Published libraries** — share components, styles, and variables across files and teams.
- **Variables** — reusable values for color, typography, spacing, and other properties; update once, reflect across linked designs.
- **Components and variants** — structured building blocks with documented properties.
- **Dev Mode** — inspect design specs and component structure for implementation.
- **Design-system scale** — organization features for libraries, consistency checks, and documentation workflows described on [Figma design systems](https://www.figma.com/design-systems/).

## Access and pricing

Figma offers multiple products and seat types (Design, Dev, and others). **Verify current plans and pricing at [figma.com](https://www.figma.com/)** before recommending a subscription.

## Use notes

Jake uses Figma especially for **setting up a design system** and a **token library** for colors and typography—foundations that downstream tools (including Paper and code) can align to. He reaches for it when he is doing **more advanced design** work that benefits from deep component, variable, and systems tooling.

When tokens live in Figma variables, keep naming and tiers documented so agents and developers map them consistently to CSS custom properties or Tailwind theme extensions.
