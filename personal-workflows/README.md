# Personal Workflows

Start with a personal outcome you want to achieve, then choose guidance that genuinely fits it.

No personal workflow playbooks are published yet. This section does not claim that examples discussed for future workflows already exist. You can still explore the [full Libraries catalog](../libraries/README.md) and [Insights](../insights/README.md), or use [Getting Started](../GETTING_STARTED.md) to describe your goals.

## Contributing a workflow

Add a real, reviewed workflow under a lowercase-hyphen outcome or project name. Explain the outcome, prerequisites, permissions, steps, and how to verify the result. Link reusable tools and lessons rather than copying them. Do not add empty placeholder folders.

Reading a workflow is not authorization to run it or change an account. See [CONVENTIONS.md](../CONVENTIONS.md#workflows).
