# beUI Pro - premium motion components

## When to use

- Purchasing motion-rich React source via a shadcn-compatible registry.
- Building animated marketing or product surfaces with paid templates.

Listed in [UI Components catalog](components.md).

A paid source-code library of animated React components, blocks, illustrations, and Next.js templates delivered through a private shadcn-compatible registry or direct source download.

## Access and licensing

**Paid.**

- Yearly: $129 per seat for one year, with premium components, animated blocks, agent skill and MCP access, and updates while active. The site states that this payment does not auto-renew.
- Lifetime: $179 per seat one time, adding illustrations, full templates, and future updates.

Installed source files remain in the project and may be customized and kept. The yearly plan limits future registry access and updates, not the continued operation of code already copied into a project. Both plans advertise unlimited personal and client projects; verify current terms before purchase or redistribution.

## Use notes

Use when motion-rich production blocks or complete templates justify the paid source access. Review copied code, dependencies, accessibility, performance, and reduced-motion behavior before adoption. This is a reference, not a registered agent skill.
