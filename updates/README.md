# Updates

Monthly changelogs for new lessons, skills, and other published material in JStack.

## File naming

One markdown file per calendar month:

`updates/YYYY-Month-update.md`

Examples:

- `updates/2026-October-update.md` — October 2026
- `updates/2027-January-update.md` — January 2027

Use **month and year** in titles and copy (for example, “October 2026”). Do not use month/day/year dates in update posts.

## Entry format

Each monthly file has a top-level heading (`# October 2026 Update`) and one or more entries. Every entry includes:

1. **Title** — same as the linked lesson or article (level-2 heading).
2. **Summary** — one or two sentences on what it covers and why it matters.
3. **Link** — a relative markdown link to the full piece in this repo (for example, `../ai-agents/lessons/build-ai-features-as-a-graph.md`).

Add newest months at the top of this README’s index when you create them.
