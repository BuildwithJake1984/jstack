# Workflows

Project-specific workflow notes and playbooks.

## Layout

When you add a workflow project, create a subfolder under `workflows/` named for the project—for example `workflows/<project-name>/`. Put a `README.md` (and any supporting markdown) inside that folder for the project index and details.

Do not add empty placeholder folders. List active projects in the table below as they are published.
